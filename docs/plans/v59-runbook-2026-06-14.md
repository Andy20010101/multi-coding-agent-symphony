# v59 Release Publication Evidence and Next Start Audit runbook

Date: 2026-06-14
Timezone: Asia/Shanghai
Goal id: `v59-release-publication-evidence-and-next-start-audit`
Branch draft: `codex/v59-release-publication-evidence-next-start-audit`
Start condition: v58 `release-closeout-operator-handoff-pack` is reviewed, merged, tagged, and released by the controller.

## Objective

v59 should turn the external v58 tag and GitHub Release actions into read-only publication evidence and a checked next-version start context.

The target path is:

```text
releaseCloseoutHandoffPack.v1
-> annotated tag evidence
-> GitHub Release evidence
-> releasePublicationEvidence.v1
-> nextVersionStartAudit.v1
```

The version is successful only if an operator can inspect the tag object, dereferenced commit, GitHub Release URL, draft/prerelease flags, asset list, publication timestamp, source refs, and next-version start state without product code creating tags, pushing tags, publishing releases, declaring release-ready, or creating the next goal automatically.

## Boundary

Allowed work:

- backend-owned `releasePublicationEvidence.v1` projection from controller-supplied tag and release evidence refs;
- read-only verification of tag object SHA, dereferenced commit, target commit, GitHub Release URL, release flags, asset list, and publication timestamp;
- copy-only next-version start audit that records whether the next runbook exists and whether the release evidence points at the expected commit;
- Workbench display of publication evidence, mismatches, blockers, rollback refs, and next-version start context;
- fixtures and tests for ready publication evidence, tag missing, tag commit mismatch, release missing, release target mismatch, unexpected assets, draft/prerelease release, unsafe local refs, and mutation-route rejection.

Forbidden work:

- `git tag`, `git push`, `gh release create`, `gh release edit`, or release publication inside product code;
- release-ready declaration from Workbench;
- direct goal event append;
- direct task completion;
- provider launch;
- Codex launch;
- Claude Code launch;
- generic shell or terminal UI;
- arbitrary command execution from Workbench;
- frontend reads of local JSONL files, provider session folders, goal ledgers, event logs, raw transcripts, or raw model output;
- automatic worktree creation;
- automatic next-version goal creation.

## Rollback path

If backend projection reads frontend files, provider session folders, local JSONL, raw transcripts, raw model output, goal ledger internals, or local release artifacts outside registered evidence refs, revert the backend projection PR.
