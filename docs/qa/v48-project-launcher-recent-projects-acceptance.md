## Source checks

`src/symphony/project-registry.js` defines `recent-projects.v1`, `current-project-binding.v1`, fixture validation, read-only boundaries, and selection-only persistence under repo-local app state. Selection changes the app-selected project binding. It does not create goal events, dispatch children, invoke providers, run jobs, write git state, tag, publish, create a GitHub Release, or write release state.

`frontend/workbench/src/api/client.js` derives default goal and run ids from `current-project-binding.v1` when the binding is bound. The route set includes `recentProjects` and `currentProjectBinding` as read-only route results.

`frontend/workbench/src/api/contracts.js` projects Recent Projects, current binding, selected project state, Project Health, route provenance, App Home state flags, and boundary flags into `DesktopAppHomeViewModel`.

`frontend/workbench/src/App.jsx` renders Project Launcher as text, lists, and status rows. It does not add a directory picker, generic command runner, provider launcher, git action, release action, or Tauri host control.
